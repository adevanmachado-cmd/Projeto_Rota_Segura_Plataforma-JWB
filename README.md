## 🚀 Funcionalidades

O sistema foi desenvolvido pensando na acessibilidade e usabilidade da comunidade escolar, emabasdo no projeto  contando com:

* **Central de Alertas Rápidos:** Botão flutuante otimizado para dispositivos móveis que direciona o usuário instantaneamente para o formulário de incidentes.
* **Abordagem Educativa:** Seção informativa detalhando os três pilares do projeto (Orientação Prática, Conscientização Contínua e Participação Ativa).
* **Espaço de Voz Estudantil:** Área dedicada para a exibição de vídeos e campanhas produzidas pelos próprios alunos.
* **Canal de Ouvidoria:** Formulário dinâmico para envio de sugestões, críticas e ideias de melhorias.
* **Relato de Riscos em Tempo Real:** Sistema de feed dinâmico (alimentado via JavaScript) para registrar e listar problemas estruturais ou acidentes perto da escola, divididos por categorias:
  * 🚦 Semáforo com Defeito
  * 🕳️ Buraco/Erosão na Via
  * 👁️ Falta de Visibilidade / Falta de Sinalização
  * 🚗 Veículo Estacionado Irregularmente
  * 💥 Acidente/Colisão

## 📱 Design e Responsividade

A interface foi projetada sob o conceito de **Mobile-First** e layouts fluídos:
* Uso de CSS Grid Inteligente (`auto-fit`) para se adaptar a qualquer tamanho de tela de smartphone ou tablet.
* Elementos de toque expandidos e otimizados para evitar cliques acidentais no celular.
* Microinterações visuais (como animações de pulso no botão de alerta) para guiar a atenção do usuário.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web puras, garantindo leveza e carregamento rápido mesmo em conexões rurais:

* **HTML5:** Estruturação semântica de todo o conteúdo.
* **CSS3:** Variáveis nativas (`:root`), Grid, Flexbox e animações customizadas.
* **JavaScript (Vanilla):** Manipulação de DOM para gerenciamento e listagem dinâmica de eventos sem dependência de frameworks externos.
